# 楽譜PDF 配置フォルダ

曲リスト（ukulele-list.html）の各曲名から、このフォルダ内のPDFへリンクしています。

## 使い方
1. 各曲のPDFを、このフォルダに **曲名そのままのファイル名** で置く
   - 例：`さんぽ.pdf` / `浜辺の歌.pdf` / `野ばら（シューベルト）.pdf`
2. コミット＆プッシュすると、リスト上の曲名クリックでPDFが開きます
3. PDF未配置の曲をクリックすると 404 になります（PDFを置けば自動で有効）

## 必要なファイル名の全リスト
`_ファイル名一覧.txt` に全100曲分のファイル名を記載。これに合わせてPDFを用意してください。
